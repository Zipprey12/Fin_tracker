# FinTracker — консольный анализатор финансовых транзакций

Консольное приложение на Java для анализа финансовых данных из файлов. Позволяет фильтровать, группировать и агрегировать транзакции в интерактивном меню с сохранением результатов аналитики.

## Технологический стек

- **Java 21**
- **Gradle**
- **Lombok** — сокращение boilerplate
- **Jackson** — сериализация данных
- **SLF4J / Logback** — логирование

## Архитектура

```
.
└── src/main/java/com/skillbox/
    ├── controller/               # Консольные меню (фильтрация, группировка, агрегация)/

    │   └── option/               # Enum-опции пунктов меню
    └── data/
        ├── model/
        │   ├── abstractions/     # Интерфейсы: AccountInfo, AccountStatement, Recurring, ...
        │   ├── dto/              # Account, Transaction и подтипы транзакций
        │   └── enums/            # TransactionType, AccountType, GroupType, AggregationType, ...
        ├── repository/

        │   └── mappers/          # LineMapper — маппинг строк файла в объекты
        └── service/              # TransactionService — фильтрация, группировка, агрегацияа, агрегация
```

## Модель данных

### Типы транзакций

| Тип | Описание |
|-----|----------|
| `Regular` | Обычная транзакция |
| `Taxable` | С налоговой ставкой |
| `Recurrent` | Повторяющаяся (hourly / daily / weekly / biweekly / monthly / yearly) |
| `ForeignCurrency` | В иностранной валюте — сумма автоматически конвертируется по курсу |
| `Commentable` | С текстовым комментарием |

### Типы счетов

`CHECKING` (текущий), `SAVINGS` (сберегательный), `CREDIT` (кредитный)

## Форматы входных файлов

Файлы передаются как аргументы командной строки. Приложение ищет их в директории `Fin_tracker/files/`.

### Транзакции (`transactions.txt`)

```
accountId,transactionId,dateTime,category,amount,type,[доп. поля]
```

Примеры:
```
10001,2,2020-01-01T12:00:00,Food,-25.50,Regular,
10001,6,2020-03-22T19:00:00,Entertainment,-45.00,ForeignCurrency,85
10002,8,2020-04-15T14:15:00,Salary,5000.00,Taxable,0.20
```

Дополнительные поля зависят от типа: для `ForeignCurrency` — курс обмена, для `Taxable` — налоговая ставка, для `Recurrent` — паттерн и количество платежей.

### Счета (`accounts.txt`)

```
accountId,accountTypeId,userId
```

Пример:
```
10001,0,201
10002,2,201
10003,0,202
```

`accountTypeId`: `0` — CHECKING, `1` — SAVINGS, `2` — CREDIT.

## Запуск

Требования: Java 21+, Gradle.

```bash
git clone <repository-url>
cd Fin_tracker

./gradlew run --args="transactions.txt accounts.txt analytics/"
```

Аргументы:
1. Имя файла транзакций
2. Имя файла счетов
3. Директория для сохранения результатов аналитики

## Работа с приложением

После запуска открывается главное меню с тремя шагами настройки аналитики:

**1. Фильтрация** — выбор транзакций для анализа:
- по диапазону дат
- по категории
- по типу транзакции
- по пользователю / счёту

**2. Группировка** — разбивка отфильтрованных транзакций по:

| Опция | Описание |
|-------|----------|
| `BY_MONTH` | По месяцу |
| `BY_YEAR` | По году |
| `BY_WEEK_DAY` | По дню недели |
| `BY_CATEGORY` | По категории |
| `EXPENSE_INCOME` | Расходы / доходы |
| `BY_ACCOUNT_TYPE` | По типу счёта |
| `BY_USER` | По пользователю |

**3. Агрегация** — итоговый расчёт по каждой группе:

| Функция | Описание |
|---------|----------|
| `SUM` | Сумма транзакций |
| `AVG` | Среднее значение |
| `COUNT` | Количество транзакций |

Результат аналитики выводится в консоль и сохраняется в указанную директорию.
